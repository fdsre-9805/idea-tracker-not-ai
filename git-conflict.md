# Конфликт в Git

## Где был конфликт

Файл README.md, строка «Статус».

Две ветки создали от main и в каждой изменили эту строку по-разному:

- ветка feature/readme-status: «Статус: в разработке»
- ветка fix/readme-wording: «Статус: идёт планирование»

Сначала в main слили feature/readme-status — прошло без проблем.
Затем слили fix/readme-wording — Git не смог сам выбрать вариант и остановился с конфликтом.

## Как исправили

1. Открыли README.md и нашли маркеры конфликта: <<<<<<<, =======, >>>>>>>.
2. Вручную оставили одну строку, объединив оба варианта: «Статус: в разработке, идёт планирование API».
3. Удалили маркеры.
4. Добавили файл в индекс и сделали отдельный коммит: «Исправлен конфликт в README.md: объединены оба статуса».
