# Трекер идей

Учебный проект для контрольной точки по Git.

Трекер идей — простой сервис, где можно записывать идеи, помечать их тегами и отслеживать статус: новая, в работе, готово, отложено.

Статус: черновик

## Файлы

- README.md — описание проекта
- project-notes.md — заметки по проекту
- api-plan.md — план API
