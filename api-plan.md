# План API

Словесный план, без кода.

## Основной объект

Идея: название, описание, теги, статус, дата создания.

## Действия

- получить список идей
- получить одну идею
- создать идею
- изменить идею
- изменить статус идеи
- найти идеи по тегу

## Возможные ошибки

- идея не найдена
- пустое название идеи
- неизвестный статус
