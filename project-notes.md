# Заметки по проекту

## Цель

Место, где идеи не теряются: записал, пометил, вернулся позже.

## Что хранится об идее

- название
- описание
- теги
- статус: новая, в работе, готово, отложено
- дата создания

## Что умеет сервис

- добавить идею
- посмотреть список идей
- изменить статус идеи
- найти идеи по тегу
